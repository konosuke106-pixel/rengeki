# 多言語対応（英語・スペイン語・中国語・韓国語）設計

## なぜ
海外で流行るオンラインゲームにする計画の第1歩。その後に「アカウントと保存」→「ガチャ（まず無料の石）」→「課金」と続ける予定で、多言語対応はそれらと独立していて先にやっても無駄にならない。

## 目標
- 画面に出る文字を、日本語・英語・スペイン語・中国語（簡体字）・韓国語で出せる
- 最初は端末の設定言語に合わせ、タイトル画面で切り替えられ、選んだ言語を覚える
- オンライン対戦では2人がそれぞれ自分の言語で見られる

## やらないこと
- 戦闘の中身（`sim.js` の動き・数値）は変えない。`sim.js` に言語の処理を入れない
- 宣伝動画（`tools/trailer.html`）、`tools/` の道具、ホーム画面アイコンは日本語のまま
- 繁体字は今回入れない

## 失敗とみなすこと
- 訳が抜けて日本語が混ざる画面がある（テストで防ぐ）
- 長い訳（特にスペイン語）でボタンや帯からはみ出し、スマホ横向きで読めない
- 戦闘の結果が言語によって変わる、オンラインで食い違う

## 作り方の候補
1. **日本語の文をそのまま「鍵」にする（採用）**：コードの日本語は残し、表示するときに `T('勝利！')` のように通して訳を引く。訳がなければ日本語のまま出る。HTML は `data-i18n` を付けた要素の中身を、起動時に日本語として覚えて差し替える。変更が小さく、今の書き方を崩さない
2. 英語の短い名前（`result.win` など）を鍵にする：一般的だが、約370行すべてを書き換えて日本語も辞書へ移すことになり、変更が大きい
3. 言語ごとに HTML を分ける：画面の作りを5重に持つことになり、直すたびにずれる

## 決めたこと（本人と合意）
- キャラ名はローマ字（例：カガリ → Kagari）で、和風の響きを残す
- 技名はその国の言葉に訳す。超必殺の帯は大きな漢字の技名をそのまま出し、訳を小さく添える（宣伝動画の字幕と同じ見せ方）
- 擬音（バキッ・ドゴォ・ガッ・ドン・ドカン など）は漫画の味としてカタカナのまま。ただし意味を伝える文字（カウンター・ジャスト！・ガード崩し・投げ抜け・よろけ・毒 など）は訳す
- 中国語・韓国語のときだけ Google Fonts から専用の字体（Noto Sans SC / Noto Sans KR）を読み込む。今の CSP の範囲内
- 翻訳は Claude が行う。ネイティブの確認はしていない状態として「保留中」に書く

## 仕組み（ビルダーへの指示）
- `src/i18n.js`：言語一覧（`ja en es zh ko` と、それぞれの自分の言葉での名前）、`T(ja, vars)`（`{name}` などを差し込む）、`setLang` / `getLang`、端末言語の判定、`localStorage` への保存（失敗しても動く）、`data-i18n` 要素の差し替え、中国語・韓国語の字体の読み込み、`<html lang>` の更新
- 訳の辞書：`src/text-en.js` などに言語ごとに1ファイル。最上位の名前は重複させない（ビルドが連結するため）。`tools/build.mjs` の `ORDER` に追加
- キャラ名・技名・技の補足・肩書き・説明・ステージ名と説明も、日本語の文を鍵に辞書で引く。同じ日本語が別の意味で使われる所があれば、その所だけ別の鍵にする
- 超必殺の帯：`sim.js` の出来事の `name`（日本語）をそのまま漢字で大きく出し、下に `T(name)` を小さく出す（日本語のときは今のまま）
- 試合の帯（第一戦・開戦！など）：日本語以外は英語の副題に合わせて訳を出す。細かい見せ方はビルダーに任せる
- 言語の切り替え：タイトル画面の小さいボタンの並び（遊び方・音・全画面）に、言語を選ぶボタンを足す。選ぶとその場で全画面の文字が変わる
- テスト `tests/i18n.test.mjs`：コード中の `T('…')` と `data-i18n`、キャラ・技・ステージのすべての文に、4言語の訳があること。差し込み `{…}` の名前が日本語と訳で一致すること。言語を変えても試合の結果（`stateHash`）が同じこと

## ビルダーに任せること
- 訳の言い回し、ボタンに収まる長さへの調整、字の大きさの微調整
- 言語ボタンの見た目（今のボタンの並びに合わせる）
- 確認：各言語でタイトル・キャラ選択・ステージ選択・対戦・一時停止・結果・オンライン・遊び方の画面をスマホ横向きの幅で見て、はみ出しがないこと
